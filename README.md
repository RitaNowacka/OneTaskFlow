# OneTaskFlow

Minimalna aplikacja PWA do wykonywania zadań po kolei.

## Uruchomienie na GitHub Pages

1. Utwórz nowe publiczne repozytorium na GitHubie.
2. Wrzuć **całą zawartość tego folderu** do głównego katalogu repozytorium.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Zapisz.
6. Po chwili GitHub poda adres aplikacji.

Na Androidzie otwórz ten adres w Chrome i wybierz **Dodaj do ekranu głównego / Zainstaluj aplikację**.

Dane zadań są przechowywane lokalnie w przeglądarce telefonu.
